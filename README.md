# آسان · ثبت‌نام و شارژ کیف پول

سایت ثبت‌نام پلتفرم خدمات مالی آسان روی `signup.asanfsp.ir`.

## فرایند

1. ورود با شماره موبایل و کد تأیید ۵ رقمی (پیامک پارس‌گرین، سرویس `SendOtp`)
2. پیام خوش‌آمد و گرفتن نام و نام خانوادگی (فقط بار اول)
3. پنل: داشبورد، کیف پول و منوی سرویس‌ها
4. کلیک روی هر سرویس: «هزینه راه‌اندازی اولیه این سرویس ۱ میلیون تومان است…» + نمایش موجودی کیف پول
5. شارژ کیف پول: وارد کردن مبلغ یا انتخاب ۱، ۳ یا ۵ میلیون تومان ← پیش‌فاکتور (فروشنده، خریدار، مبلغ، مالیات ۱۰٪)
6. دکمه پرداخت: پیام «امکان ارتباط با درگاه پرداخت برقرار نشد. لطفاً بعداً تلاش نمایید.»

صفحه‌های عمومی: `/about` درباره ما، `/contact` تماس با ما، `/terms` قوانین و مقررات.

## فنی

- Node.js 20.12 به بالا، **بدون هیچ پکیج اضافه** (نیازی به `npm install` نیست)
- `server/index.mjs` سرور و API، `server/sms.mjs` پیامک، `server/store.mjs` ذخیره کاربران و پیش‌فاکتورها در `data/db.json`
- `public/` صفحه‌ها، استایل، اسکریپت‌ها، فونت وزیرمتن (روی خود سرور، بدون CDN)
- همه تنظیمات و اطلاعات فروشنده در `.env` (نمونه: `.env.example`)؛ `.env` و `data/` هیچ‌وقت در گیت نمی‌روند
- کلید پارس‌گرین همان کلید پروژه صورتحساب درمان است. پارس‌گرین فقط به IP ایران جواب می‌دهد، پس از همان تونل (`PARSGREEN_TUNNEL=127.0.0.1:9102`) استفاده می‌شود.

## اجرا برای آزمایش

```bash
cp .env.example .env    # SMS_PROVIDER=console: کد در گزارش سرور چاپ می‌شود
npm start               # http://127.0.0.1:3100
```

## فایل‌های استقرار

- `deploy/asan-signup.service` سرویس systemd (مسیر `/opt/asan-signup`، کاربر `asan`، پورت داخلی 3100)
- `deploy/nginx-signup.conf` تنظیم Nginx برای `signup.asanfsp.ir`؛ گواهی Let's Encrypt با certbot

## به‌روزرسانی روی سرور

```bash
cd /opt/asan-signup && sudo -u asan git pull && sudo systemctl restart asan-signup
```

## اتصال درگاه پرداخت (بعداً)

فعلاً `POST /api/invoices/:id/pay` همیشه پیام عدم ارتباط با درگاه را برمی‌گرداند. بعد از گرفتن درگاه، همین مسیر به درگاه وصل می‌شود و با تأیید پرداخت، وضعیت پیش‌فاکتور `paid` و مبلغ به موجودی کیف پول اضافه می‌شود.
